# 名医入企 · 北京大学国际医院企业健康合作平台

面向保险公司、企业与员工健康福利场景的 H5 预约演示站。

## 演示能力

- 三级专家资源：大咖医生 / 主任专家 / 专业医生
- 专家墙：40 位专家照片、科室、职称与擅长方向，资料来自北京大学国际医院官网
- 预约流程：选择层级与档期、选择专家、提交企业需求
- 「我的预约」：查看预约状态及院方回复的课题、内容、流程、时间与联系人
- 院方工作台：登录后回复预约、更新状态、配置短信提醒模板与触发节点
- 数据保存在浏览器 `localStorage`，无需后端即可演示完整闭环
