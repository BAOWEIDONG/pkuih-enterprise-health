# 名医入企 · 北京大学国际医院企业健康合作平台

面向保险公司与企业客户的企业健康服务 H5 演示站，适配微信内置浏览器与手机端访问。
页面采用北京大学国际医院深蓝品牌色与 iOS 风格移动端界面，桌面访问时以 480px 手机预览框居中显示。

## 在线演示

https://baoweidong.github.io/pkuih-enterprise-health/

## 演示能力

- 机构账号采用手机号白名单：仅超级管理员开通的手机号可登录；首次登录须完整填写姓名、职务、单位、机构类型、联系方式和通知邮箱（机构类型含保险公司、银行、证券、基金、信托、企业、事业单位与其他机构）
- 登录页提供企业演示账号「一键进入」，固定手机号 `13800000001`、验证码 `888888`，无需先注册
- 企业资料中的所在省市不再手工填写，自动跟随定位或首页切换的城市，并在城市变化时同步更新
- 通知邮箱为必填项，用于生成方案更新与预约确认邮件；联系方式默认取登录手机号，可修改
- 直接通过微信内置浏览器打开 H5，不依赖公众号授权；使用手机号验证码登录并持久化登录状态
- 自动恢复上次身份：上次为院方账号会直接进入院方工作台，上次为企业账号会保持企业登录态
- 三级专家资源：大咖医生 / 主任专家 / 专业医生
- 59 位专家以“照片/默认头像 + 科室职称 + 擅长简介 + 可服务类型”的信息卡展示，点击可查看完整专家详情
- 专家与履约医院绑定；机构登录后优先展示就近医院可预约专家，并可随时切换到全部地区
- 进入首页自动请求定位并计算到各履约医院的距离；定位不可用时按登录省市回退，可在首页手动切换医院
- 首页切换履约医院时同步该院所在城市与本地专家范围，避免异地医院出现“0 位可约”的假象；医院下拉按实际定位距离排序
- 时令主题：首页展示当前医院当月的独立主题封面，点击进入主题介绍页查看本月疾病重点、适合行业、推荐课题、绑定专家与覆盖城市，并可直接预约
- 月度主题配置：每家医院独立维护 12 个月时令名称、介绍、关注疾病、行业、课题、主讲专家与讲座覆盖城市；每个课题只需选择一次主讲专家，专家详情只展示本院主题中绑定给该专家的当月课题
- 默认医疗头像：表格未提供性别时统一使用中性医疗头像；院方也可按需选择男/女及资深头像
- 找不到合适专家时，机构可提交活动提需；医院运营可记录电话沟通、匹配专家并关闭需求
- 专家库筛选栏在向下浏览时固定在顶栏下方，切换层级或搜索无需回到页面顶部
- 专家库默认展示当前地区、当前医院的可预约专家，默认不启用月份时令筛选；启用月令后仅展示讲座，并可一键清除月令筛选
- 移动端图片分层加载：首图和列表使用轻量缩略图，专家详情图仅在打开详情时加载
- 服务类型：`讲座`、`健康咨询`、`1V1报告解读` 严格按院方专家配置匹配；当前医院没有对应专家时，预约页直接引导发起提需
- 三级预约流程：专家为必选项，按专家申请周期选择有号源的日期（只到天，不划分时段）；已选专家再次点击可取消
- 预约页将“查看简介”与“选择专家”拆分为独立操作；时令主题为可选项，点击选择、再次点击取消
- 全国省市联动：覆盖 34 个省级行政区与 380 个城市级选项，预约时按省份加载对应城市，活动详细地址必填
- 预约号源：超级管理员与医院运营可按专家个人配置每日可预约数量；号源页统一为“选专家 → 批量设置 → 单日微调 → 统一保存”，支持未来 7/14/30 天快捷范围与当前专家/本院全部专家批量应用；早于专家预约周期的日期自动跳过，号源不得低于当日已预约数量
- 「我的预约」按登录账号隔离，可查看状态及院方回复的课题、大纲、流程、时间与项目组联系人
- 预约履约流程：机构提交预约 → 医院运营接单并填写活动方案 → 机构确认或提出修改 → 医院运营执行并归档
- 院方工作台：仅限已分配且启用的院方账号登录，支持接单、回复活动方案、确认方案、安排项目组以及活动结束后归档
- 院方角色：仅保留超级管理员与医院运营。超级管理员拥有全部医院权限，医院运营负责本院专家、号源、接单与项目跟进
- 医院账号：超级管理员可在「医院与账号」中创建、编辑、停用医院运营账号，并为每家医院分配运营人员；医院运营只能维护本院数据
- 专家配置：超级管理员与医院运营可新增或编辑本院专家，按院方表格维护姓名、履约机构、科室/任职、科室方向、服务类型、履约城市、擅长/专业优势、简介/履历、预约提前期并上传照片；已绑定时令课题的主讲专家会校验讲座服务能力与履约机构，避免配置冲突
- 专家筛选：专家库可按月份时令与科室方向筛选，切换时只局部刷新结果并保留当前浏览位置
- 履约城市：专家覆盖城市使用省份/城市联动选择；月度主题保留院方表内履约地口径。含“京外”或“省外”的履约地统一按全国可履约处理
- 筛选一致性：服务类型、可约状态、梯队、科室、搜索与月份时令共用同一筛选结果集，筛选计数、空状态和专家卡片保持一致
- 时令履约地独立：普通讲座、健康咨询、1V1 报告解读按专家日常履约城市判断；时令主题与预约按具体课题的履约地判断，两套范围互不混用
- 展业海报：超级管理员统一配置官方海报；医院运营可下载、分享官方海报，也可上传本院自有海报并分享给客户
- 宣传海报：预置 4 套院方标准海报，突出医院权威、名医资源与服务价值；海报不展示项目人员姓名和联系方式，仅保留预约二维码
- 海报加载：预置 4 套 1080×1920 轻量 WebP 海报与缩略图，列表只加载缩略图，打开预览时才加载完整海报；上传海报会自动压缩，避免现场生成拖慢操作
- 院方人员自动带入：处理预约时，当前登录人员的姓名与手机号会自动填入项目组联系人和推送通知
- 活动地点分工：省份、详细地址与场地名称由机构预约/详情中填写，机构可单独修改；院方方案只读展示并自动同步，不覆盖机构填写内容
- 活动备注：企业可填写活动需求备注，院方内部备注采用查看/编辑两种状态展示，仅院方可见
- 推送通知：院方填写课题确认信息后，按该机构与提需人的当前资料自动组合生成个性化通知；复制推送内容后，自动视为已推送并记录人员与时间
- 推送入口：院方工作台不再单设「短信」标签，统一在预约详情的「推送通知」卡片内查看并复制；标签栏更精简
- 院方入口：已从「我的」移动到首页最下方
- 全部演示数据保存在浏览器 `localStorage`，无需后端即可演示预约闭环
- 首次打开自动写入 3 条企业预约样例（待接单、方案待确认、已确认）和 2 条提需样例，登录演示账号即可直接体验完整流程
- 页面不展示价格、报价或费用信息
- 支持安卓微信边缘滑动返回：弹层、登录页、院方工作台与二级地点编辑均按层级返回，不会直接退出业务页面
- 浏览器滚动恢复由应用统一管理：关闭弹层、切换筛选或返回列表时保留原浏览位置，不会被浏览器历史恢复覆盖
- 登录、筛选、切换层级、选择日期与专家均使用局部刷新，不重建整页，并保留当前浏览位置

## 说明

本项目为静态交互 Demo：

- 验证码固定为 `888888`，不会实际发送
- 页面不依赖微信公众号授权，直接分享 H5 链接即可在微信内置浏览器访问
- 推送通知仅生成并复制内容，不调用短信网关；复制推送内容或“号码和内容”后才视为已推送
- 推送记录保存在浏览器本地，正式版本需接入真实发送状态与审计系统
- 推送功能只负责生成和复制号码及内容，仍需院方在手机短信应用中自行发送
- 院方演示账号和密码保存在浏览器本地，未接入真实身份认证与权限审计；正式上线必须改为后端鉴权
- 专家上传照片会压缩后保存在浏览器本地，正式版本需接入对象存储、图片审核与内容管理后台
- 展业海报由超级管理员维护官方素材，医院运营可上传本院自有素材并保存、下载或分享；海报不含项目人员姓名和手机号，二维码统一指向企业健康服务平台；正式版本建议接入渠道参数、分享追踪与素材审核
- 号源配置与预约记录目前共用一个浏览器本地数据源，正式版本需接入后端库存、并发锁与订单系统
- 账号鉴权、真实预约库存、消息通知与文件上传需在正式版本中接入医院业务后端

专家照片与简介来自北京大学国际医院官网公开资料，仅用于本项目演示。实际出讲专家、活动排期与授权以院方最终确认为准。

医院地址与经纬度按公开地图信息整理；深圳北医康复医院当前使用南山区近似坐标，正式上线前需由院方核实门牌地址与定位点。

## 技术说明

- 当前演示仍为原生 JavaScript 单页实现，业务状态集中在 `assets/app.js`，样式在 `assets/styles.css`
- 技术团队已确定正式版本采用 Vue 3。当前阶段优先稳定业务闭环与移动端交互，Vue 3 组件化迁移作为下一阶段单独实施
- `index.html` 加载压缩后的 `assets/app.min.js` 与 `assets/styles.min.css`；源码修改后执行：

```bash
npx esbuild assets/app.js --minify --legal-comments=none --outfile=assets/app.min.js
npx esbuild assets/styles.css --minify --legal-comments=none --outfile=assets/styles.min.css
```

- 专家、医院、时令主题与主题匹配数据位于 `assets/data/*.json`，全国省市数据位于 `assets/china-cities.json`
- 院方 1124 表格更新后，可执行 `python3 work/build-expert-data.py [表格路径]` 重新生成专家、时令主题与课题匹配数据；脚本会校验医院绑定、服务类型、履约城市和专家重复
- 12 张月度时令封面位于 `assets/themes/`，由医院运营选择月份后在机构端展示
- 月度主题的院方配置保存在浏览器 `localStorage` 的 `pkuih_h6_theme_config`，正式版本需接入医院内容管理后端
- 官网专家图片按卡片图与详情图分别存放于 `assets/doctors/cards/`、`assets/doctors/details/`，默认头像位于 `assets/avatars/`
- 预置展业海报位于 `assets/posters/`（WebP），缩略图位于 `assets/posters/thumbs/`，海报设计源文件位于 `work/poster-tools/build-promo-posters.cjs`；超级管理员上传的官方海报与医院自有海报保存在浏览器 `localStorage` 的 `pkuih_h6_marketing_posters`
- 正式版本建议由后端提供登录鉴权、号源库存与并发控制、预约状态机、推送发送记录与图片对象存储
- 全系统回归可执行 `node work/qa-system-full-audit.cjs`（1700+ 项断言）与 `node work/qa-state-regression.cjs`，覆盖数据完整性、筛选到预约的一致性、医院城市联动、专家履约地编辑、滚动位置恢复、登录态、安卓返回、号源批量保存与内部备注
